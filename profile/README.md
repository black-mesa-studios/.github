# Black Mesa Studios

A small open-source organization based in Poland. We build libraries, tools and low-level projects, and release them under permissive licenses.

## Projects

| Project | Language | Description |
| --- | --- | --- |
| [system-parse-lib](https://github.com/black-mesa-studios/system-parse-lib) | Python | A library for parsing system information on Linux: OS name, kernel, uptime, desktop and session, CPU and GPU models and vendors. [Docs](https://black-mesa-studios.github.io/system-parse-lib/) |
| [CEMU](https://github.com/black-mesa-studios/CEMU) | C++ | Cool Emulator, a simple 16-bit custom-ISA emulator. |
